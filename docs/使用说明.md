# 跑伴 RunMate v1.2.0 使用说明

> 配合「i大工-体质测评-健康长跑」使用的独立安卓 App
> 无需 root / 无需 Google 服务 / 不读取你 i大工 的任何数据，定位与提醒全部在本机完成

---

## 1. 安装

1. 安装 `DUT-RunMate_v1.2.0.apk`（约 5.8 MB，minSdk 24 / Android 7.0+，targetSdk 34）；
   - 从 v1.0/v1.0.1 升级：直接覆盖安装；**v1.2.0 会自动修正历史地图点选点位的坐标偏差**（旧版换算算法有误，详见下文「历史数据迁移」）；
   - 从 v1.1.0 升级：直接覆盖安装，无额外操作；
2. 首次打开时按提示授予：位置（精确）、通知、后台位置（建议选「始终允许」，跑步息屏更稳）；
3. 进「设置」→ 底部 → 点 **电池优化白名单**（加入白名单，防止跑步中被系统杀进程）。

## 2. 录入 8 个打卡点（两种方式，二选一或混用）

### 方式 A：现场标定（推荐，最准）
1. 人站到打卡点 **中心位置**（操场点位就站在第 4 跑道那条弧线上）；
2. 打开「标定」页，等精度收敛（±10m 内更佳，页面实时显示精度/卫星数）；
3. 选采集时长（10/20/30 秒）→ **开始平均标定**：App 会做精度加权平均并给出「±精度 · 离散半径」；
4. 命名（如「西山操场1号」）→ **保存为打卡点**。半径建议默认（App 会按 GPS 精度自动给 20~30m）。

### 方式 B：地图选点（v1.2.0 准星确认流）
1. 「地图」页（图源为高德，国内直连秒开）：双指缩放到最深 20 级（约 0.1m/像素，跑道线清晰可见）；卫星/街道可切换（卫星约 18 级、街道 20 级，卫星更深处自动放大 18 级瓦片）；
2. **点按或长按**地图任意位置 → 出现**橙色准星标记**与底部确认栏（实时显示该点 WGS-84 坐标）；
3. **拖动准星**微调位置，双指放大地图核对落点（准星几何中心即精确坐标点），确认无误后点 **「确认添加」**；
4. 弹出新增面板：可查双制式坐标、手改坐标、调半径、命名 → 保存；点「取消」则移除准星不建点；
5. **拖动图钉**可微调已有点；点图钉可编辑/删除；
6. 已知 GCJ-02 坐标（如从高德取的）→ 面板里切 GCJ-02 制式输入，自动换算。

> 地图上的蓝色圆点是你的实时位置（带半透明精度圈）：**蓝点 = GPS 定位**，**灰点 = 网络定位（精度较低仅作参考）**。若蓝点长期不出现，到开阔处等 GPS 首次定位。

> 也可以先用 B 粗放 8 个点，再逐个到现场用 A 精修（列表里点条目即可编辑）。

## 3. 跑步（配 i大工 原 App 双开使用）

1. 正常打开 i大工 的健康长跑跑步页（开始计跑）；
2. 回到跑伴 → 「跑步」页 → **开始跑步**（出现常驻通知=后台运行中）；
3. 戴上耳机，正常跑。跑伴会自动：
   - 接近点位（默认 60m，可调）：语音「前方 XX 米，点位名，请准备」；
   - 进入检测圈：提示音 + 「已进入 X 号检测区」；
   - **API 判定开启时**：出圈后宽限期内核查「跑步距离」接口，距离增量达标 → 语音「X 号点，打卡成功」+ 轻震；未达标 → 语音「注意，X 号点未确认打卡」+ 急促震动 + 警示音 —— 这时**减速折返再过一次该点**即可（漏卡点位状态会自动重置等待补卡）；
   - 结束时弹小结（确认/漏卡清单 + 用时 + 自测距离）。
4. 息屏不影响运行（前台服务 + WakeLock + 电池白名单）。

## 4. 启用「API 判定」（漏卡提醒的开关）

不开启时只有进出圈提示，**无法判定是否真的打上卡**。开启步骤见《i大工-健康长跑_API接口详细文档.md》§5/§6：
1. 抓包拿到「查询跑步距离」接口（一次 10 分钟）；
2. 「接口」页填令牌 → 编辑「跑步距离查询」模板 → **发送测试**直至能提取到距离值；
3. 「设置」→ 打开「API 判定」。

之后检测逻辑（用户方案的原样实现）：

```
进入检测圈（半径可设）→ 锁定距离基线 → 每 N 秒轮询接口
    距离增量 ≥ 阈值(默认3m)  ⇒ 打卡成功 ✓（语音+短震）
    出圈后宽限(默认12s)仍无增量 ⇒ 漏卡！强提醒 ⚠
```

## 5. 应用内更新（v1.1.0 起）

1. 手机浏览器打开**发布中心**页面（即本项目 Web 首页）→ 「App 内更新配置」卡片 → 复制「更新检查地址」；
2. 跑伴 → 设置 → 更新 → 粘贴到「更新服务器地址」→ 点**立即检查更新**验证连通；
3. 之后每天启动 App 自动静默检查一次；有新版本会弹窗展示说明，点「立即更新」自动下载（含进度条与 SHA256 校验）并拉起安装；
4. 不填服务器地址 = 仅走 GitHub Release 通道（国内网络可能不可达，建议配置服务器地址）；
5. Android 8+ 首次安装更新需授予「安装未知应用」权限，App 会自动引导。

## 6. v1.2.0 定位精度修复与历史数据迁移

**旧版问题**：v1.1.0 及之前 GCJ-02 换算算法存在抄写错误，导致地图上定位/环线/标定点显示偏移最多约 570m（用户体感一两百米~几百米不等），且地图点选录入的打卡点实际存储位置有偏差。

**v1.2.0 修复**：
- 换算算法已修正（与业界标准实现一致，往返误差 < 1cm）；
- 首次启动时**自动迁移**历史地图点选点位（source=manual）到正确坐标，无需手动处理；现场 GPS 标定的点位本就正确，不受影响；
- 网络定位（基站/Wi-Fi）自动归一坐标后再参与显示与检测，GPS 优先，蓝点不再跳动；
- 蓝点附带精度圈，一眼看出当前定位可信度。

> 迁移只发生一次（完成后写入标记文件）。若你曾手动键入过 WGS-84 坐标建点，建议升级后到点位编辑面板复核一遍。

## 7. 参数速查（设置页）

| 参数 | 默认 | 说明 |
|---|---|---|
| 默认检测半径 | 25 m | 新增点位时的半径；单个点位可在编辑面板单独调（10~100m） |
| 预告距离 | 60 m | 提前语音预告 |
| 确认距离增量 | 3 m | 接口距离增长多少米算打卡成功 |
| 轮询间隔 | 3 s | 进圈后查接口的频率 |
| 出区宽限 | 12 s | 出圈后等多久判漏卡（给服务端上传留时间） |
| 语音/提示音/震动 | 全开 | 可独立开关 |
| 自动检查更新 | 开 | 每天启动时静默检查一次（服务器 + GitHub 双通道） |

## 8. 常见问题

- **跑步中没声音**：检查媒体音量；TTS 用的是导航播报通道，会走当前耳机；无 TTS 数据时自动降级为提示音。
- **被系统杀了**：确认电池白名单；小米/华为等在设置里再允许「自启动」。
- **坐标显示怎么和网上查的不一样**：网上多为高德 GCJ-02（大连地区偏移约 450m），App 显示的是 GPS 原始 WGS-84；两种制式在弹窗中同时展示，输入时可切换。
- **地图上的图钉位置准吗**：准。地图用高德瓦片（GCJ-02 制图），App 在显示和点选两侧自动换算，图钉压住的位置就是存储点位对应的真实地面位置（v1.2.0 修正算法后已实测验证）。
- **蓝点是灰色的**：当前只有网络定位（室内/GPS 未首定位），精度较低仅作参考；到开阔处等 GPS 变蓝。
- **令牌过期**：接口页出现 401/提取失败 → 重新登录 i大工 → 重新抓一次 Cookie 更新令牌。

## 9. 隐私与边界

- 所有数据（点位、设置、令牌）仅存本机 `filesDir`；不上传任何服务器；
- 定位检测全部在本机完成；接口调试只访问你配置的那一个 URL；
- 仅供个人跑步提醒与本人账号接口调试，请勿用于改成绩/批量请求等用途。
