# 跑伴 RunMate v1.6.2 使用说明

> 配合「i大工-体质测评-健康长跑」使用的独立安卓 App
> 无需 root / 无需 Google 服务 / 不读取你 i大工 的任何数据，定位与提醒全部在本机完成

---

## 0. v1.6.2 更新速览（本次修复）

- **修复「发送测试 / 查询服务端距离」报「请求异常 PatternSyntaxException」**：旧版在 Cookie 为空时用了一段含 `\{` 转义的正则去删除空请求头，这个写法在 Android 14+ 系统的新正则引擎上无法编译——所以两个测试按钮点下去请求根本没发出去，和学校服务器、网络、账号都无关。本版改为 JSON 解析后逐值替换，彻底移除正则拼接
- **修复「统一身份登录后令牌不自动填充」**：实测健康长跑 H5 页面一加载就会发出 findExtExercise 查询，而旧版嗅探器要等页面加载完成才注入，永远错过这条请求——这就是登录成功但配置一直不入库的根因。本版改为拦截 H5 页面本体、在任何页面脚本运行之前就预注入嗅探器，且只采纳 HTTP 200（会话有效）的请求；捕获成功后返回「接口」页，令牌立即回填
- **其他**：URL 占位符无值时给出明确提示（不再报晦涩的非法 URL）；WebVPN 隧道地址自动修正为用户专属前缀

## 1. 安装

1. 安装 `DUT-RunMate_v1.6.2.apk`（约 5.9 MB，minSdk 24 / Android 7.0+，targetSdk 34）；
   - 从 v1.0/v1.0.1 升级：直接覆盖安装；**v1.2.0 会自动修正历史地图点选点位的坐标偏差**（旧版换算算法有误，详见下文「历史数据迁移」）；
   - 从 v1.1.0 升级：直接覆盖安装，无额外操作；
2. 首次打开时按提示授予：位置（精确）、通知、后台位置（建议选「始终允许」，跑步息屏更稳）；
3. 进「设置」→ 底部 → 点 **电池优化白名单**（加入白名单，防止跑步中被系统杀进程）。

## 2. 录入 8 个打卡点（两种方式，二选一或混用）

### 方式 A：现场标定（推荐，最准）
1. 人站到打卡点 **中心位置**（操场点位就站在第 4 跑道那条弧线上）；
2. 打开「标定」页，等精度收敛（±10m 内更佳，页面实时显示精度/卫星数）；
3. 选采集时长（10/20/30 秒）→ **开始平均标定**：App 会做精度加权平均并给出「±精度 · 离散半径」；
4. 命名（如「西山操场1号」）→ **保存为打卡点**。半径建议默认（App 会按 GPS 精度自动给 20~30m）。

### 方式 B：地图选点（v1.2.0 准星确认流）
1. 「地图」页（图源为高德，国内直连秒开）：双指缩放到最深 20 级（约 0.1m/像素，跑道线清晰可见）；卫星/街道可切换（卫星约 18 级、街道 20 级，卫星更深处自动放大 18 级瓦片）；
2. **点按或长按**地图任意位置 → 出现**橙色准星标记**与底部确认栏（实时显示该点 WGS-84 坐标）；
3. **拖动准星**微调位置，双指放大地图核对落点（准星几何中心即精确坐标点），确认无误后点 **「确认添加」**；
4. 弹出新增面板：可查双制式坐标、手改坐标、调半径、命名 → 保存；点「取消」则移除准星不建点；
5. **拖动图钉**可微调已有点；点图钉可编辑/删除；
6. 已知 GCJ-02 坐标（如从高德取的）→ 面板里切 GCJ-02 制式输入，自动换算。

> 地图上的蓝色圆点是你的实时位置（带半透明精度圈）：**蓝点 = GPS 定位**，**灰点 = 网络定位（精度较低仅作参考）**。若蓝点长期不出现，到开阔处等 GPS 首次定位。

> 也可以先用 B 粗放 8 个点，再逐个到现场用 A 精修（列表里点条目即可编辑）。

## 3. 跑步（配 i大工 原 App 双开使用）

> **v1.3.0 起随时可定位查看**：不开跑步，「跑步」页即实时定位预览（标题显示「定位预览 · GPS ±Xm」/「网络定位 ±Xm」），最近点位距离与雷达方向同步刷新；「地图」页左上角常驻定位源徽章（GPS 蓝/网络橙/搜索中灰），点按徽章可看定位源说明。想开跑随时点「开始跑步」。

1. 正常打开 i大工 的健康长跑跑步页（开始计跑）；
2. 回到跑伴 → 「跑步」页 → **开始跑步**（出现常驻通知=后台运行中）；
3. 戴上耳机，正常跑。跑伴会自动：
   - 接近点位（默认 60m，可调）：语音「前方 XX 米，点位名，请准备」；
   - 进入检测圈：提示音 + 「已进入 X 号检测区」；
   - **API 判定开启时**：出圈后宽限期内核查「跑步距离」接口，距离增量达标 → 语音「X 号点，打卡成功」+ 轻震；未达标 → 语音「注意，X 号点未确认打卡」+ 急促震动 + 警示音 —— 这时**减速折返再过一次该点**即可（漏卡点位状态会自动重置等待补卡）；
   - 结束时弹小结（确认/漏卡清单 + 用时 + 自测距离）。
4. 息屏不影响运行（前台服务 + WakeLock + 电池白名单）；
5. **立即核对（v1.3.0）**：跑步中随时点按首页右上「服务端距离」，下个瞬间即请求一次 findExtExercise 并核对（不用等自动轮询）；未跑步时点按则直接查询一次官方距离。

## 4. 启用「API 判定」（漏卡提醒的开关）

不开启时只有进出圈提示，**无法判定是否真的打上卡**。开启步骤：

1. 按《i大工-健康长跑_API接口文档.md》§5 抓包一次（约 5 分钟，拿到 userId/amId/pmId/sign 与 Authorization 令牌）；
2. 「接口」页「**健康长跑距离 findExtExercise**」模板 **v1.3.0 起已预填实测接口**：把抓包的 `amId/pmId/sign/userId` 填进请求体、`userId:accessToken` 整串粘到令牌栏（校外把 URL 换成 WebVPN 隐道地址）→ **发送测试**直至能提取到距离值（旧版本如模板为空，App 升级后自动补填）；
3. 「设置」→ 打开「API 判定」。

**打卡核对判定标准**（= 服务端距离变长 且 此时经过打卡区域）：

```
跑步全程：每 15s 锚点轮询一次官方距离（维持基线新鲜）
进入检测圈（半径可设）→ 基线 = 进区前最后一次轮询到的官方距离（30s 内有效）
    区内每 N 秒(默认3s)轮询：距离增量 ≥ 阈值(默认3m，RFID 命中一次=+100m 必触发)
        ⇒ 打卡成功 ✓（语音+短震）
    出圈后宽限(默认12s)仍无增量 ⇒ 漏卡！强提醒 ⚠（减速折返再过一次即可补卡）
```

> 基线为什么取「进区前」的距离：RFID 读卡器注册打卡往往先于 App 的下一次轮询——
> 若等进区后才取基线，基线可能已包含这次 +100m，就永远检测不到增量了（v1.3.0 修复）。

## 5. 应用内更新（v1.1.0 起）

1. 手机浏览器打开**发布中心**页面（即本项目 Web 首页）→ 「App 内更新配置」卡片 → 复制「更新检查地址」；
2. 跑伴 → **「设置」Tab**（v1.3.0 起为底部导航第 5 页，也可点右上角齿轮）→ 更新 → 粘贴到「更新服务器地址」→ 点**立即检查更新**验证连通；
3. 之后每天启动 App 自动静默检查一次；有新版本会弹窗展示说明，点「立即更新」自动下载（含进度条与 SHA256 校验）并拉起安装；
4. 不填服务器地址 = 仅走 GitHub Release 通道（国内网络可能不可达，建议配置服务器地址）；
5. Android 8+ 首次安装更新需授予「安装未知应用」权限，App 会自动引导。

- **设置一级页面**：底部导航新增「设置」Tab（第 5 个），检测参数/提醒/更新/系统入口一眼可见，不用再找右上角齿轮；「关于」区块动态显示当前版本号；
- **随时定位预览**：不开跑步，「跑步」页即实时定位（标题「定位预览 · GPS ±8m」样式），最近点位距离 + 雷达方向同步刷新；地图页同样可看（此前版本已支持）；
- **定位源徽章与说明**：地图顶部常驻徽章——「GPS · ±Xm」（蓝，精度高）/「网络定位 · ±Xm」（橙，室内兜底）/「定位搜索中…」（灰）。**为什么有时显示网络定位**：GPS 需直视卫星，室内/楼宇遮挡下无法锁定，App 自动回落到网络定位（基站/WiFi，误差几十至几百米）；到室外开阔处静止半分钟 GPS 锁定后自动切回蓝点。App 始终 GPS 优先（20~30s 内有 GPS 定位时忽略网络定位）；
- **打卡核对增强**：接口模板预填实测 findExtExercise；基线取进区前距离（见 §4）；「服务端距离」可点按立即核对/查询。

## 7. v1.2.0 定位精度修复与历史数据迁移

**旧版问题**：v1.1.0 及之前 GCJ-02 换算算法存在抄写错误，导致地图上定位/环线/标定点显示偏移最多约 570m（用户体感一两百米~几百米不等），且地图点选录入的打卡点实际存储位置有偏差。

**v1.2.0 修复**：
- 换算算法已修正（与业界标准实现一致，往返误差 < 1cm）；
- 首次启动时**自动迁移**历史地图点选点位（source=manual）到正确坐标，无需手动处理；现场 GPS 标定的点位本就正确，不受影响；
- 网络定位（基站/Wi-Fi）自动归一坐标后再参与显示与检测，GPS 优先，蓝点不再跳动；
- 蓝点附带精度圈，一眼看出当前定位可信度。

> 迁移只发生一次（完成后写入标记文件）。若你曾手动键入过 WGS-84 坐标建点，建议升级后到点位编辑面板复核一遍。

## 8. 参数速查（设置页）

| 参数 | 默认 | 说明 |
|---|---|---|
| 默认检测半径 | 25 m | 新增点位时的半径；单个点位可在编辑面板单独调（10~100m） |
| 预告距离 | 60 m | 提前语音预告 |
| 确认距离增量 | 3 m | 接口距离增长多少米算打卡成功 |
| 轮询间隔 | 3 s | 进圈后查接口的频率 |
| 出区宽限 | 12 s | 出圈后等多久判漏卡（给服务端上传留时间） |
| 语音/提示音/震动 | 全开 | 可独立开关 |
| 检查更新 | 设置页按钮 | 服务器不可达自动转 GitHub（v1.6.0 起界面仅一个按钮） |

## 10. 常见问题

- **跑步中没声音**：检查媒体音量；TTS 用的是导航播报通道，会走当前耳机；无 TTS 数据时自动降级为提示音。
- **被系统杀了**：确认电池白名单；小米/华为等在设置里再允许「自启动」。
- **坐标显示怎么和网上查的不一样**：网上多为高德 GCJ-02（大连地区偏移约 450m），App 显示的是 GPS 原始 WGS-84；两种制式在弹窗中同时展示，输入时可切换。
- **地图上的图钉位置准吗**：准。地图用高德瓦片（GCJ-02 制图），App 在显示和点选两侧自动换算，图钉压住的位置就是存储点位对应的真实地面位置（v1.2.0 修正算法后已实测验证）。
- **蓝点是灰色的/显示「网络定位」**：室内或遮挡下 GPS 无法锁定，App 自动回落到网络定位（误差几十至几百米，坐标已自动归一只作参考）；到室外开阔处静止半分钟，GPS 锁定后自动切换为蓝点（点地图顶部徽章可看说明）。
- **网络定位和 GPS 差多少**：GPS 室外精度一般 3~10m；网络定位（基站/WiFi）几十至几百米。跑步判定用的坐标始终 GPS 优先（20~30s 内有 GPS 就忽略网络定位），不受影响。
- **不开跑步能看定位吗**：能（v1.3.0）。「跑步」页自动进入定位预览，「地图」页看蓝点/徽章。
- **令牌过期**：接口页出现 401/提取失败 → 重新登录 i大工 → 重新抓一次 Cookie 更新令牌。

## 11. 隐私与边界

- 所有数据（点位、设置、令牌）仅存本机 `filesDir`；不上传任何服务器；
- 定位检测全部在本机完成；接口调试只访问你配置的那一个 URL；
- 仅供个人跑步提醒与本人账号接口调试，请勿用于改成绩/批量请求等用途。
